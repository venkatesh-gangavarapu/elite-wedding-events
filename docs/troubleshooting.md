# Troubleshooting Guide

## Website unavailable
Check DNS resolution, deployment status, browser cache and HTTPS.

## Admin login failure
Check Supabase configuration, user existence, site/redirect settings, browser console and network response.

## Image upload failure
Check authentication, Storage bucket, Storage policies, file type/size and Supabase response.

## Images slow
Check image dimensions, optimization result, browser Network panel, cache behavior and number of first-view images.

## www hostname issue
Check DNS and Cloudflare hostname configuration and confirm HTTPS coverage.

## SEO not appearing
Check `robots.txt`, `sitemap.xml`, canonical URL, Google Search Console and page accessibility.
